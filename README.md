# ГОСТ Конвертер

Программа для автоматического оформления курсовых и дипломных работ по ГОСТ. 
Загрузите документ Word (.docx) — получите правильно отформатированный файл.

## ⚠️Инструкция перед использованием:

Так как сделать полностью автоматизированную программу для редактирования совершенно разных документов довольно трудно, перед конвертацией документ должен обладать некоторыми требованиями по оформлению:

1.  Ни должны быть применены какие-то стили, в том числе и нумерованные списки (все должно быть написано простым текстом, стиль можно применить только к маркерным спискам), иначе программа неверно определит заголовки.
2.  Любые заголовки должны начинаться с числа без точки (1 Текст, 1.1 Текст, 1.1.1 Текст).
3.  Строки, которые вы хотите объединить в нумерованный список должны начинаться с числа с точкой, напоминаю – без стиля! (1. Текст).
4.  Листинги должны быть написаны строго шрифтом Courier New, чтобы программа их верно определила.

Также, перед началом конвертации внимательно прочитайте ограничения программы и помните: программа не делает ваш документ идеальным, она выполняет лишь 80 процентов работы, но некоторые моменты вам придется отредактировать самим.


## 🚫 Ограничения программы



### Что требует ручной проверки и исправления:
- **Изображения** — программа определяет их наличие, но оставляет текстовые заглушки
- **Сложные таблицы** — с объединёнными ячейками или особой структурой могут форматироваться некорректно, также продолжение таблицы на другом листе надо подписывать самому
- **Библиографический список** — проверьте оформление ссылок и списка литературы по ГОСТ Р 7.0.100-2018
- **Математические формулы и уравнения** — довольно редко встречаются, поэтому их программа не обрабатывает
- **Типография** — Знаки препинания, кавычки и т.п надо писать вручную 
- **Приложения** — требуют отдельного оформления, не обрабатываются автоматически

### Технические ограничения:
- **Формат файлов** — работает только с .docx, не поддерживает .doc, .pdf, .odt
- **Объём документа** — при обработке файлов больше 100 страниц возможны замедления
- **Сложная вёрстка** — документы с колонками, сносками, особыми разделами обрабатываются не полностью
- **Язык** — оптимально работает с русскоязычными документами

**Возможно некоторые функции будут доработаны в дальнейшем, но пока ограничения именно такие**

## 📦 Установка

1. Убедитесь, что у вас установлен Python 3.8 или выше
2. Скачайте все файлы программы в одну папку
3. Откройте командную строку в этой папке
4. Установите библиотеку:

```bash
pip install python-docx
```

## 🚀Запуск
Запустите файл main.py:
```python main.py```

---
## 🖱️ Как пользоваться

1. **Выберите файл** — нажмите кнопку 📁 и выберите ваш документ Word (.docx)
2. **Укажите, куда сохранить** — программа предложит имя автоматически
3. **Нажмите "Конвертировать"** 
4. **Ждите** — внизу будет прогресс-бар и сообщения о процессе
5. **Готово!** — откроется папка с вашим отформатированным документом

📌 **Совет:** Сохраняйте исходный файл — программа создаёт копию.
